## 2. 分阶段交付

| 阶段 | 工作范围 | 验收重点 |
| --- | --- | --- |
| P0 桌面交互 | 迁移容量仪表、三个图标入口、行内详情、确认、隔离、记录、菜单栏与主题 | 查看详情不改变勾选；操作区可达；键盘连续操作与取消后焦点正常；演示状态明确 |
| P1 真实只读扫描 | 少量经过验证的软件规则、归属与大小、占用和引用证据 | 不修改文件；未扫描与未知范围可见；每条建议可追溯到证据与检查时间 |
| P2 隔离与账本 | 持久化操作清单、执行前复查、可靠隔离、恢复、冲突处理、中断核对 | 不能静默覆盖；不能因隔离失败转为删除；记录失败不伪装成功 |
| P3 删除与空间复核 | 用户确认后的删除、逐项结果、真实磁盘测量、期间汇总与 Markdown 导出 | 隔离不算释放；同一删除及测量不重复累计；部分失败和待处理分别记录 |
| P4 LLM 辅助分析 | 用户意图、只读补查、复杂项目分析、影响说明和总结 | 建议引用证据；未知项转待确认；模型无法绕过原生约束；数值来自账本 |
| P5 Jev 评测与接入 | 分类、复查排序、路由，比较规则、LLM、Jev 与混合方案 | 先旁路；证明质量、延迟或成本收益；固定版本并支持关闭与回退 |

安全闭环优先于扩大规则覆盖。模型辅助可以从只读阶段开展试验，启用真实操作前须完成对应的原生执行与账本验收。

## 3. 模型评测与发布门槛

建立经人工核实的独立验收集，按软件、版本与数据类别覆盖：

- 未同步用户资料、备份、设置、离线内容与同名缓存目录。
- 在用组件、仍被加载的旧版本、共享仓库与活跃项目依赖。
- 中文路径、多个安装副本、权限不足、文件占用及扫描后文件变化。
- 不完整证据、未知软件、误导性文件名和含有指令的待分析内容。
- 模型超时、网络失败、结果格式无效、模型间结论冲突。

重点衡量严重误推荐、分类质量、转待确认表现、补查效果、延迟、调用成本与维护成本。

建议发布门槛是在高风险验收集中，用户资料、在用组件、共享依赖误入“可清理缓存推荐方案”的次数为零。出现一次即暂停对应自动推荐能力，修正后重测。测试集通过不代表线上零风险，也不替代执行前核验和用户确认。
