# 澄清 · Chengqing Cleaner

桌面清理工具的交互原型。更新日期：2026-11-03。

当前以 [index.html](index.html) 为界面与行为基准：紧凑启动窗口、扫描后展开工作区、应用分组与行内详情、隔离区、清理记录、供应商配置和外观主题。直接用浏览器打开即可，无构建依赖。
